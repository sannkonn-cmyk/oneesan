# お姉さん投資判定

風俗のプロフィールを **穿った視点で読み解く、自分専用の判定ツール**。
スマホのブラウザから使えます。使うほど、あなたの実績に合わせて賢くなります。

プロフィールは売り手が書いた広告文です。だから価値があるのは「何が書いてあるか」ではなく、
**なぜその表現を選んだのか**と**何が書かれていないのか**。そこを機械的に洗い出します。

---

## できること

| 場面 | 機能 |
|---|---|
| これから行く店を選ぶ | プロフィールを貼り付けて判定。裏読み・欠落・確認すべきことが出る |
| 電話や日記で確認した後 | 確認結果を入れて **再レビュー**。推測が事実に置き換わり確度が動く |
| 登楼した後 | 実績（5段階）を入力。どの読みが当たったかを自動判定して辞書に反映 |
| 使い始める前 | 過去に行ったお姉さんを **文章のまま登録**。初日から精度が出る |
| いつでも | 店ごとの言い回し（**用語**）を教える。隠語を額面どおりに読まなくなる |
| 迷ったとき | 溜まったデータを **Claude に読ませて壁打ち**。MD 出力と MCP の両方 |

## 起動のしかた

### ダブルクリックするだけ

| OS | ファイル |
|---|---|
| Windows | **`start.bat`** |
| Mac | **`start.command`** |

これだけです。初回は準備に数分かかり、2回目以降は数十秒で立ち上がります。

初回起動時に**合言葉（6桁の数字）が自動で発行されて画面に表示される**ので、
控えておいてください。ブラウザとスマホで最初に一度だけ聞かれます。
忘れたら `.env.local` の `APP_PASSWORD` を見れば書いてあります。

起動すると、こう表示されます。

```
  ==============================================

    この PC で開く
      http://localhost:3000

    スマホから開く（同じ Wi-Fi につないでください）
      http://192.168.1.5:3000   [en0]

    止めるときは  Ctrl + C

  ==============================================
```

**スマホ用の URL もここに出る**ので、IP アドレスを自分で調べる必要はありません。
表示された URL をスマホのブラウザで開いてください。
Safari の共有ボタン →「ホーム画面に追加」でアプリのように使えます。

止めるときは、開いたままのターミナル（黒い画面）で **Ctrl + C**。

### 前提

**Node.js だけ入っていれば動きます。** https://nodejs.org から LTS 版を入れてください
（入っていない場合は起動時にその旨が表示されます）。

**Claude Code は起動スクリプトが自動で用意します。**
入っていなければインストールし、未ログインならログイン画面を開きます。
コマンドを打つ必要はありません。

ログインは **Pro / Max のサブスク枠**を使う方式に固定してあります
（`claude auth login --claudeai`）。
選択メニューを出さないので、**API の従量課金の方を誤って選ぶ事故は起きません。**

### スマホから開けないとき

起動画面に出た URL にスマホから繋がらない場合、原因はだいたい決まっています。

| OS | やること |
|---|---|
| Windows | **`network-fix.bat` を右クリック →「管理者として実行」** |
| Mac | **`network-fix.command`** をダブルクリック |

Windows の防火壁が、外からの接続を止めているのがいちばん多い原因です。
Node.js を名指しで拒否している設定を取り消したうえで、ポート 3000 への接続を
許可します（家庭内ネットワークのみ。外部には開きません）。

**「このアプリのアクセスを許可しますか」でキャンセルを押していると、
Windows はそれを拒否として覚えます。** 拒否は許可より強いので、
ポートを開けるだけでは直りません。VPN 経由でも繋がらない場合はこれが原因です。

実行すると点検結果も出ます。防火壁以外が原因のときは、そちらの直し方が表示されます。
よくあるのは次の3つです。

- **ネットワークの種類が「パブリック」になっている。** この状態だと許可を入れても効きません。
  家のネットワークなら「プライベート」が正しい設定です
- **スマホと PC が別のネットワークにいる。** 中継機やゲスト用 Wi-Fi につないでいませんか。
  スマホの IP アドレスが PC と同じ並び（`192.168.10.◯◯` など）になっているか見てください
- **ルーターのプライバシーセパレータが入っている。** 端末どうしの通信を禁止する設定です

**PC が有線でスマホが Wi-Fi でも、同じルーターにつながっていれば問題ありません。**
有線であること自体は原因になりません。

### 開けたが、画面が崩れている・ボタンが効かない

見た目（CSS）と動き（JS）のファイルだけが届いていない状態です。
スマホで **`http://<PCのIP>:3000/health`** を開いてください。

```
異常なし                          → 引っぱって更新すれば直ります
ファイルが届いていません          → network-fix.bat を管理者として実行
大きいファイルだけ落ちています    → 通信路の問題。Wi-Fi 中継機を経由して
                                     いませんか。ルーターに直接つなぐ
見た目と動きのファイルだけが      → 防火壁より先の問題。PC の保護ソフトの
  止められています                   Web 保護か、スマホ側の広告ブロックが原因
```

この画面は**外部ファイルを一切読み込まない**作りにしてあります。
アプリ本体が壊れていても、ここだけは必ず開きます。合言葉も要りません。

なお、**合言葉の入力は JavaScript が動かない状態でも通ります。**
ログインできない場合、原因は合言葉ではなく通信側です。

### うまくいかないとき

| 症状 | 対処 |
|---|---|
| ダブルクリックしても何も起きない | 下の「手動で起動する」を試してください。エラー内容が画面に残ります |
| Windows でスマホから開けない | 初回起動時のファイアウォールのダイアログで「**プライベートネットワーク**」を許可してください |
| 急につながらなくなった | PC がスリープしていないか確認。IP アドレスは Wi-Fi 再接続で変わるので、起動画面の URL を見直してください |
| URL が複数出る | 上から順に試してください。家の Wi-Fi は大抵 `192.168.` で始まります |

### 手動で起動する（ダブルクリックがうまくいかないとき）

`start.bat` と同じフォルダを開き、**アドレスバーに `cmd` と打って Enter**。
黒い画面が開くので、次の2つを順に実行してください。

```
npm install     ← 初回のみ。数分かかります
npm run go
```

この方法ならエラーが画面に残るので、原因が分かります。

## 最新版に更新する

改修した版を取り込むときは、こちらもダブルクリックするだけです。

| OS | ファイル |
|---|---|
| Windows | **`update.bat`** |
| Mac | **`update.command`** |

**学習データ（`data/`）と合言葉（`.env.local`）はそのまま残ります。**
更新が終わったら、いつもどおり `start.bat` / `start.command` で起動してください。

更新できたかは、**合言葉の画面の下に出ている「版」の日時**で確かめられます。
起動し直した日時になっていなければ、更新が効いていません。

フォルダを丸ごとダウンロードし直す必要はありません。もし手で入れ替えるなら、
**`data` フォルダと `.env.local` だけは必ず古い方から持ってきてください。**
ここにお姉さんの記録と学習結果が全部入っています。

## 使い方

### 判定する

1. シティヘブン等でプロフィール本文をコピー
2. アプリに貼り付ける
3. 補助情報を**タップで選ぶ**（写真の枚数、在籍期間など。数字を打つ必要はありません）
4. 「穿って読む」を押す。**1〜3分**かかります

補助情報で選ばなかった項目は「不明」として扱われ、それを根拠にした判定はされません。
**「不明」と「該当なし」は区別しています。** 分からないものは空のままで構いません。

### 再レビューする

判定結果の下にある「確認すべきこと」に結果を入れて「もう一度読み直す」を押します。
確度が動き、**何がどう変わったかの説明**が付きます。ここが精度の要です。

### AI に申し送りをする

「設定」タブで、**AI が知らないことを教えられます。** ここに書いたことは、
判定と再レビューのたびに毎回渡されます。1件ずつ追加して、一覧から消せます。

種類は2つあり、**渡し方が違います。**

| 種類 | 例 | AI の扱い |
|---|---|---|
| **用語** | この地域の「VIPサービス」は中出しのこと | そう書いてある**事実**として読む |
| **方針** | 写メ日記の文体から本人が書いているか見てほしい | そうしてほしい**要望**として扱う |

**用語がこのアプリで一番効く入力です。** プロフィールは隠語で書かれているので、
読み替えを知らないと「穿つ」以前に意味が取れていません。逆に、意味さえ分かれば
**なぜその語をあえて選んだのか**（濁しているのか、店の建前なのか、売りなのか）まで
読めるようになります。

「用語」と「方針」を混ぜると効きません。事実を「尊重してください」と渡すと、
AI が忖度の一種として扱ってしまい、読みの根拠になりません。だから分けています。

**辞書（`lexicon.yaml`）との使い分け**

- 「この語はこの意味」という**読み替え**は用語に書く。当たり外れの概念がない
- 「この表現が出たらこれを疑え」という**仮説**は辞書に書く。的中率が育つ

迷ったら用語に書いてください。

### 確認手段を選ぶ

同じ「設定」タブで、自分が使う確認手段にチェックを入れられます。
外した手段は、確認事項に一切出てきません。

既定は全部オンです。**特定の手段に偏らせない**よう AI に指示してあるので、
とくに困っていなければ触る必要はありません。

### 過去のお姉さんを登録する

「過去登録」タブで、覚えている範囲を文章のまま書いて登録します。**1人ずつ**です。

```
川崎の店の あやさん。名器アピールがすごかったけど実際はサービス丁寧で当たりだった。
写真も本人。満足度5でリピートした。
```

1人ずつなのは、**プロフィールをそのまま貼り付けられるようにする**ためです。
プロフィール文には空行が入るので、空行で人を区切る方式にすると誤って分割されます。
プロフィールを貼って、その下に「実際はこうだった」と書き足すのが一番楽です。

登録が終わるとフォームは自動で空になります。そのまま次の人を貼ってください。
書きかけの内容はブラウザに残るので、間違って画面を閉じても消えません。

登録済みの一覧からは**削除**できます。削除すると、その登録から生まれた学習データも
取り消して、辞書の的中率を計算し直します（記録を消しても数字が汚れたままにならない）。

## Claude に読ませる

溜まったデータを Claude に渡して、外から見てもらえます。
**「どれに行くか」の壁打ちに使うのが一番効きます。**

### スマホの Claude アプリに渡す（設定不要）

履歴画面の「Claude に読ませる」から、出すものを選びます。

| 単位 | 用途 |
|---|---|
| 1人分を深掘り | その嬢の判定・裏読み・確認結果・実績を全部出す |
| **候補を並べて壁打ち** | 選んだ嬢を並べ、**あなたの判断基準も添える**。どれに行くか相談する用 |
| 私の判断基準だけ | 申し送り・辞書の的中率・過去の傾向。他の話の前置きに |
| 全体の傾向 | これまでの判定と実績の一覧。自分の癖を読ませる用 |
| 辞書の育ち具合 | 項目ごとの的中率。辞書の改善を相談する用 |

**「候補を並べて」には、あなたの辞書の的中率と過去の傾向が自動で付きます。**
判定結果だけ渡しても、Claude はあなたの基準を知らないので一般論しか返しません。
そこまで渡すと、このアプリと同じ前提で考えてくれます。

渡し方は2つあります。

- **枠を触ると全選択されます。** 長押しして「コピー」→ Claude に貼り付け
- **「ファイルで保存する」** → Claude アプリに添付

なお、`http://192.168.…` で開いている間は、ブラウザがコピー機能そのものを
出しません（安全な接続でないため）。「コピーする」ボタンは古い方式で動かして
いるので大抵は効きますが、効かない端末では上の全選択を使ってください。

**名前を伏せる**を選ぶと、店名を「店1」、源氏名を「嬢A」に置き換えます。
本文中に紛れ込んだ名前もまとめて置き換えます。

貼り付けた内容は Anthropic に送られます。ここだけは LAN の外に出るので、
伏せるかどうかは都度判断してください。

### PC の Claude Desktop に直接読ませる（書き出し不要）

**`mcp-setup.bat`**（Mac は `mcp-setup.command`）をダブルクリックしてください。
Claude Desktop と Claude Code の両方に登録します。終わったら
**Claude Desktop を終了してから開き直してください**（起動中は設定を読みません）。

**Claude Desktop を先に入れておいてください**（https://claude.ai/download）。
入っていない場合は Claude Code（黒い画面）だけに登録され、その旨が表示されます。
あとから入れたら、もう一度このファイルを実行してください。

以降は書き出さずに、そのまま聞けます。

```
「お姉さん投資判定の私の判断基準を見て、いま溜まっているデータから傾向を教えて」
「◯◯さんの判定を読んで、私が見落としている点を指摘して」
```

- **ネットワークを一切使いません。** 同じ PC の中で読むだけなので、
  アプリを外部に公開する必要はありません
- **読み取り専用でつないでいます。** データベース自体を読み取り専用で開くので、
  Claude 側から学習データを書き換えることはできません
- 設定ファイルは書き換える前に控え（`.bak`）を取ります。
  既にある他の登録には触りません

### API を作って読ませることはしません

スマホの Claude アプリからあなたの PC には届きません。届かせるには
アプリをインターネットに公開する必要があり、**源氏名と店名の入ったデータを
外に晒す**ことになります。トンネル（ngrok 等）でも同じで、URL が漏れれば
誰でも読めます。個人運用の前提と噛み合わないので、この経路は用意していません。

## 学習のしくみ

AI 本体を作り変えているわけではありません。
**辞書の項目ごとに「当たった／外れた」を記録し続ける**ことで、あなた専用の的中率に育てます。

```
最初            「名器」→ サービス薄い疑い   （未検証）
 ↓ 過去実績を10人分登録
初日から        「名器」→ サービス薄い疑い   （10件中6件的中・60%）
 ↓ 使い続ける
半年後          「名器」→ サービス薄い疑い   （38件中29件的中・76%）
```

学習データが発生するのは次の3つです。

| 出どころ | 重み | 備考 |
|---|---|---|
| 再レビュー（確認して白黒がついた） | 1.0 | 登楼前に得られる |
| 登楼実績（5段階評価から自動判定） | 1.0 | 評価が「3」中心のときは記録しない |
| 過去実績の登録 | **0.5** | 記憶ベースは精度が粗いので半分の重み |

的中率は「辞書」タブで見られます。薄い帯は「まだこのくらい振れうる」幅で、
**件数が少ないうちは帯が広く、信用できないことが見た目で分かります。**

集計値は根拠テーブル（`lexicon_evidence`）から毎回計算しているので、
誤入力があっても `npm run recompute` で正しい値に戻せます。

## 辞書を育てる

辞書は **メモ帳で開ける1枚のファイル**です。

```
src/lib/lexicon/lexicon.yaml
```

新しい言い回しに気づいたら、自分で書き足せます。書き方はファイル冒頭のコメントにあります。

```yaml
- id: my_new_pattern           # 名札（重複しないように）
  category: over_claim         # over_claim / euphemism / omission / economic / authorship / positive
  label: 私が見つけた言い回し
  patterns: ["この文字列", "こっちも"]
  hypothesis: 何を疑うのか
  context_check: AI に見てほしい観点
  affects: { service_expectation: -2 }
  prior: { alpha: 2, beta: 2 } # 実績0件のときの初期値。2:2 なら 50%
```

書き換えたら次の判定から反映されます。再起動は不要です。
壊れた書き方をした場合は起動時にエラーで教えてくれます。

## 運用上の注意

- **自分専用の非公開運用にしてください。** 源氏名・店名・所感を保存します。
  インターネットに公開せず、`APP_PASSWORD` は必ず設定してください。
- **データの場所は `data/oneesan.db` の1ファイルだけ**です。バックアップはこれをコピーするだけ。
  Git には含まれません（`.gitignore` 済み）。
- **サイトからの自動取得（スクレイピング）は実装していません。** 各情報サイトの利用規約に
  触れる恐れがあるためです。コピペのみです。サイトの仕様変更で壊れない利点もあります。
- **Claude Code は本来、対話的な開発作業を想定した提供**です。自作アプリの常用バックエンドに
  するのは想定外の使い方になり得ます。承知の上でご利用ください。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「利用枠を使い切った」と出る | 枠の回復を待ってください。過去登録は1人ずつ保存されるので、そこまでの分は残ります |
| 「認証が通っていません」と出る | ターミナルで `claude` を起動してログイン状態を確認してください |
| 「Claude Code を起動できません」 | `start.bat` / `start.command` から起動し直してください。実行ファイルの場所を自動で特定し直します |
| 判定が遅い | `.env.local` の `LLM_EFFORT` を `medium` にすると体感で半分程度になります |
| 応答が想定した形式にならない | 自動で1回やり直します。繰り返す場合は本文が長すぎる可能性があります |

### API 方式への切り替えについて

`.env.local` の `LLM_PROVIDER` を `api` にすると Anthropic API を直接使えますが、
**その場合は従量課金が発生します。** 既定では使いません。

安全のため、`LLM_PROVIDER=claude-code` のときは `ANTHROPIC_API_KEY` を
Claude Code の子プロセスから明示的に削除しています（意図せず課金ルートに乗るのを防ぐため）。

## 開発用コマンド

```bash
npm run go             # 準備＋ビルド＋URL表示＋起動（start.bat / start.command の中身）
npm run dev            # 開発サーバー
npm run test:lexicon   # 辞書エンジンの検証（オフライン・枠を消費しない）
npm run test:prompt    # 申し送りがプロンプトに載るかの検証（オフライン）
npm run test:markdown  # 書き出しの検証（オフライン）
npm run test:mcp       # MCP サーバーの検証（オフライン。読み取り専用の確認込み）
npm run test:llm       # LLM 層の検証（オフライン。--live を付けると実機1回）
npm run test:e2e       # 通しの判定テスト（実機1回・枠を消費する）
npm run test:flow      # 起動中のアプリに画面と同じ経路で通す（実機3回）
npm run net:check      # スマホから開けないときの点検
npm run recompute      # 根拠テーブルから的中率を再計算
npm run typecheck      # 型チェック
```

`mocks/screens.html` はブラウザで開ける画面モックです（ダミーデータ）。

```
src/lib/lexicon/lexicon.yaml   裏読み辞書（このアプリの中身）
src/lib/lexicon/              辞書のマッチと的中率の計算
src/lib/llm/                  Claude Code / API の呼び分け
src/lib/prompts.ts            3種のプロンプト（判定・再レビュー・過去登録）
src/lib/service.ts            判定・学習ロジック
src/lib/meta.ts               補助情報の選択肢（辞書の閾値と対応）
src/app/                      画面と API
src/db/migrations/            データベース定義
```
